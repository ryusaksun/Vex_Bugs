# Vex Bug Tracker

这里是 **Vex** — V2EX 社区 iOS 客户端的 Bug 反馈仓库。

## 如何提交 Bug

请通过 [Issues](https://github.com/ryusaksun/Vex_Bugs/issues/new) 提交，包含以下信息：

### 必填项

- **Bug 描述**：简要说明遇到的问题
- **复现步骤**：按顺序列出复现 Bug 的操作步骤
- **预期行为**：你认为正确的表现是什么
- **实际行为**：实际发生了什么

### 可选项（有助于更快定位问题）

- **截图 / 录屏**：能直观展示问题
- **设备信息**：iPhone 型号、iOS 版本
- **Vex 版本**：可在 设置 → 关于 中查看
- **出现频率**：每次都能复现 / 偶尔出现 / 仅出现过一次

## Issue 标签说明

| 标签 | 含义 |
|------|------|
| `bug` | 已确认的 Bug |
| `duplicate` | 重复提交 |
| `enhancement` | 功能建议（非 Bug） |
| `wontfix` | 不予修复 |
| `fixed` | 已修复，等待发版 |

## 关于 Vex

Vex 是一个使用 SwiftUI 构建的 V2EX 原生 iOS 客户端，支持 iOS 18.0+。

## 联系

如果不方便使用 GitHub Issues，也可以在 V2EX 上联系开发者。
